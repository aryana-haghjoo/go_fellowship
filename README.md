## About the Research

This research focuses on developing physics-informed deep learning frameworks to super-resolve low-resolution galaxy spectra by a factor of ~10 in spectral resolution. Using paired JWST/NIRSpec observations from the public JADES survey, the work demonstrates how neural networks trained with domain-specific constraints can recover astrophysically meaningful information from data that would otherwise be scientifically limited.

The methodology is transferable to future missions and spectroscopic surveys, with implications for:
- Measuring galaxy properties at high redshift
- Constraining reionization history through Lyman-alpha diagnostics
- Extending statistical samples to fainter sources via low-resolution spectroscopy
